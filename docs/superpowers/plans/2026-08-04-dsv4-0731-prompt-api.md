# DeepSeek V4 Flash 0731 Prompt and API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Match OMLX's DeepSeek V4 0731 prompt protocol and expose correct thinking, assistant prefill, tool calls, and finish behavior through EXO's dashboard, Chat Completions API, and Responses API after the backbone/tensor-RDMA plan is stable.

**Architecture:** Keep EXO's API adapters and canonical `TextGenerationTaskParams`. Change only the DeepSeek V4 preparation branch in `utils_mlx.py`, the vendored V4 encoder features needed by that branch, and the two streaming parsers that consume V4 output. Generate immutable prompt goldens from the local OMLX reference, test rendered text and token IDs, then validate the same semantics through streaming and non-streaming API adapters and the live two-node instance.

**Tech Stack:** Python 3.13, EXO API adapters, Pydantic request types, the vendored DeepSeek V4 encoder, OMLX's local chat-template reference, pytest/pytest-asyncio, MLX tokenizer utilities, OpenAI-compatible Chat Completions and Responses schemas.

## Global Constraints

- Start only after every completion gate in `2026-08-04-dsv4-0731-backbone-rdma.md` passes.
- Preserve generic API adapters and generic `developer`-to-`system` consolidation unless a committed 0731 golden proves a specific incompatibility.
- Keep EXO's current empty-system tool-schema injection; OMLX performs the same injection.
- Do not wire unused encoder `context` plumbing, replace the entire output parser, or perform unrelated dead-code cleanup.
- Treat OMLX as a read-only reference. Generate and commit goldens; do not require OMLX at ordinary EXO test runtime.
- Do not expose DSML markup in visible content. Malformed output may become an error or safe text according to the existing parser contract, but it must not hang a stream.
- Preserve reasoning as a separate channel in both APIs. The model's hidden chain-of-thought must not be merged into ordinary assistant content.
- Use the exact target model ID `Jundot/DeepSeek-V4-Flash-0731-oQ4e-mtp` in live tests.
